Anderson six-color baseline policy for v3.0.18:
- Orange: #FF0D00 (255,13,0)
- Pink: #FF0024 (255,0,36)
- Yellow: #FFFF44 (255,255,68)
- Green: #28FF00 (40,255,0)
- Blue: #0D00FF (13,0,255)
- Purple: #5B00E6 (91,0,230)

Existing built-in event palettes, saved event overrides, custom lights/presets, custom scheduled presets, and Favorite Colors are normalized to these baselines on upgrade. Favorite Colors reset to exactly these six values. Event/schedule IDs and timing remain unchanged.

# Anderson Home v3.1.57

## Changed
- User-facing schedule, dawn, and dusk times now display in 12-hour format with AM/PM.
- Internal schedule values remain in 24-hour HH:MM form so existing time inputs, saved settings, and scheduler behavior are unchanged.
- Schedule 2 summary now converts fixed start/end times to the same 12-hour display format.

## Preserved
- Existing dawn/dusk calculations, time zone and DST behavior.
- Existing schedules, NVS settings, PINs, BLE behavior, OTA partitioning, and frozen Android APK.

# Anderson Home 3.1.27 — Atelier

A complete visual reinvention: illuminated sculpture profile chooser, architectural live house canvas, pale-blue intensity dial and master console, integrated motion selectors, schedule ribbon, named color collection, editorial page titles, scene collection cards, and chapter-based settings navigation.

All original control scripts and functions remain intact. The presentation layer moves the original live elements and retains their event handlers, identity and access restrictions. Firmware logic, BLE and Wi-Fi behavior, persistence, backups, signed OTA checks, partition layout and recovery remain unchanged, apart from the version constant.

Validation exercises a simulated controller at 320/390/768/1280 pixels, including rejected PINs, successful profile login, restricted-profile visibility, actual power/brightness/effect/resume request handlers, navigation, settings and layout. Screenshots are inspected before production publication. The test does not establish physical-controller installation or device acknowledgement.

# Anderson Home v3.1.47

- Replaces the separate **Check for Remote Update** and **Install Verified Remote Update** buttons with one **Remote Update** button.
- One tap now checks the signed manifest, verifies the release, downloads it, installs it to the inactive OTA slot, and reboots automatically.
- Existing signature, SHA-256, firmware identity, rollback, and update-hold protections remain in place.

# Jason Home 2 NanoC6 1.0.6 local curtain bridge

Oracle is the sole Eufy, schedule and AI authority. NanoC6 runs local Wi-Fi and SmartDawn BLE only; no direct Eufy login, UPnP or DDNS.

Automated checks cover protocol vectors, image headers, flash layout, migration and architecture. Hardware boot, Wi-Fi reconnection, BLE writes and update installation require verification on the user's controller. They have not been physically verified here.

The layout remains minimal factory updater plus one runtime. There is no automatic previous-image rollback. A failed single-slot write is recovered through the permanent browser uploader or USB. Keep 1.0.3 recovery files. Do not automatically install this candidate until hardware validation.
